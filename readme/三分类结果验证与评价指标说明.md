# 三分类结果验证与评价指标说明

本文说明当前 `paint / pollution / aging` 三个病害头的验证方法。`pigment` 是 paint 内部的四类颜料像素标签，应另做四分类统计，不与三类病害指标混写。

## 验证链路

1. 准备五波段场景：450、550、600、650、700 nm。
2. 在 UI 中完成人工标注并复核 `paint.png`、`pollution.png`、`aging.png` 和 `pigment.png`。
3. 按“原始实物板/场景”划分 train、val、test；同板不同光照或方向副本必须绑定同一 split。
4. 用未参与训练的场景运行指定权重和阈值。
5. 将预测 mask 与人工真值逐像素比较，同时检查 overlay。
6. 分背景角色、病害类型和复杂场景汇总结果。

不能按 patch 随机打散后再评价，否则同一块板可能同时出现在训练集和测试集。训练 loss 也不能替代独立真值评价。

## 当前输入口径

原始输入为 `five_band.npy`。当前 `background4` 模型使用 19 通道：

- 5 个原始波段；
- 4 个一阶差分；
- 4 个相邻比值；
- 2 个归一化差分；
- 4 个背景角色通道。

论文版本1/2的旧实验使用 15 通道，不应与当前 `background4_v2 / v3 / v3_agingfix_v1` 的结果直接混算。

## 常用像素指标

- `IoU = TP / (TP + FP + FN)`
- `Dice = 2TP / (2TP + FP + FN)`
- `Precision = TP / (TP + FP)`
- `Recall = TP / (TP + FN)`

三个病害头分别计算。`pigment` 只在人工确认的 paint 区域内评价，可报告每类 IoU、宏平均 IoU 和混淆矩阵；ignore 像素不进入分母。

## 当前必须增加的专项指标

| 项目 | 主要观察 |
| --- | --- |
| 石青背景上的代赭 | `paint` 召回率，防止真实代赭被压成背景 |
| 大面积颜料 | `paint` 召回率和连通区域完整性 |
| 石青纯背景老化 | `aging` 召回率及 `paint` 误报面积 |
| 四种纯背景板 | 各头误报面积占比 |
| 复杂混合板 | 三头的漏检、串类和重叠情况 |

## 版本比较要求

比较 v3 与微调版时必须固定：

- 相同测试场景和人工真值；
- 相同背景角色；
- 相同 tile 参数与 composition mode；
- 相同阈值，或明确标注各自校准阈值；
- 相同后处理开关。

`SAMPLE_094–096` 没有可用的正式真值且存在背景归属冲突，只能做外部目视检查，不能用于正式定量结论。
