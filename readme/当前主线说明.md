# 当前主线说明

## 数据链路

```text
相机5张BMP
-> camera_eval_workspace/SAMPLE_xxx
-> five_band.npy + preview.png
-> 人工确认背景板
-> 模型预测
-> 人工复核masks
-> patch导出与候选训练
```

## 当前模型链

```text
background4_v2
-> background4_v3
-> background4_v3_agingfix_v1_best
```

| 版本 | 定位 |
| --- | --- |
| `background4_v2` | UI中background4推理默认版本 |
| `background4_v3` | 吸收097–119后的10轮候选 |
| `background4_v3_agingfix_v1_best` | 从v3继续微调，采用最佳第4轮 |

background4 固定使用19通道和四背景条件，输出：

- paint
- pollution
- aging
- 四类像素级pigment

## UI review链

UI仍保留论文 version 2 的softcomp起标链：

```text
validation_v10_balanced_softcomp_5056_pollthr035
```

它用于产生可编辑标注草稿，不等于background4默认版本。

## 当前数据

- 冻结基础集：40场景、1,500 patch
- v3增量集：23场景、846 patch
- v3总清单：63场景、2,346 patch
- `SAMPLE_094–096`：不入训；当前无确认真值且背景记录冲突
- `SAMPLE_097–119`：已经采用并进入v3增量集

## 当前正式入口

- 相机导入：`train/six_band_dataset.py`
- 训练：`train/run_training.py`
- 预测：`train/predict.py`
- UI工作流：`train/workbench_workflow.py`
- UI目录：`ui/analysis_workbench`

## 当前重要目录

```text
train/camera_eval_workspace
train/five_band_patches/background4_v1
train/five_band_patches/background4_v3
train/experiments/five_band_train/task_specific
train/experiments/five_band_predictions/task_specific
ui/analysis_workbench
```

注意：

- `five_band_patches/background4_v1` 仍是v2/v3冻结基础集，不能删除。
- 不同模型版本必须写入不同预测目录。
- 不同背景板样本必须分开预测。
- UI保存或采用标注不会自动训练。
