# `background4_v1` 历史版本说明

> 本文件仅用于保留版本沿革。当前预测、UI 和迁移均不应再以 `background4_v1` 为主版本。

`background4_v1` 是四背景角色进入模型后的早期训练版本。它位于当前 `background4_v2 → background4_v3 → background4_v3_agingfix_v1` 主线之前，数据覆盖、背景硬负样本和老化修正均不如后续版本完整。

## 与当前版本的关系

| 版本 | 定位 | 当前用途 |
| --- | --- | --- |
| `background4_v1` | 四背景角色早期基线 | 仅历史对照 |
| `background4_v2` | 40 场景 / 1,500 patch 冻结基线 | 回归对照、UI 可切换 |
| `background4_v3` | 在 v2 基础上纳入 097–119 等增量数据 | 当前完整 v3 基线 |
| `background4_v3_agingfix_v1` | 从 v3 继续微调，重点修正 aging | 当前老化微调对照 |

## 使用限制

- 不要把论文中的“版本1”与 `background4_v1` 混为一谈。论文版本1/2属于旧的 15 通道实验；`background4` 属于当前 19 通道链路。
- 不要用本文件中的历史描述推导当前训练样本、标签口径或部署文件。
- 当前规则以 [训练学习规则](训练学习规则.md) 为准，当前版本链路以 [当前主线说明](当前主线说明.md) 为准。

如需复现实验，必须同时固定当时的代码、权重、数据清单、split 和阈值；只保留一个旧 `.pt` 不能视为完整可复现版本。
