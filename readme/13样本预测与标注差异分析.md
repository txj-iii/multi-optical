# 13 样本预测与标注差异分析（历史归档）

> 本文对应 `epochs_7 / epochs_8 / epochs_9` 和早期 `retune_9` 阶段，不代表当前 `background4` 主线。

历史分析曾围绕早期 13 个样本及后续 `SAMPLE_017–019` 比较：

- `epochs_7_pollution70_agingfix`
- `epochs_8_oldnew_tuned`
- `epochs_9_tuned_compare`
- `retune_9_stable_v1`
- `retune_9_paintfix_v1`
- 按 head 融合的候选结果

当时的主要观察是：

- 稳定基线的背景误报较低，但部分新板 `paint` 偏弱；
- paint 修复版本能提高主体召回，但不适合作为三个 head 的整体替代；
- 按 head 融合可以保留较稳定的 `pollution / aging`，同时替换较强的 `paint`。

这些结论只用于解释早期实验为何走向后续的任务特定微调，不能直接推导当前版本优劣。当前模型已增加四背景角色条件、采用 19 通道输入，并扩展到 `background4_v2 / v3 / v3_agingfix_v1`。

如需重新比较，应使用当前权重、完整人工真值和 [三分类结果验证与评价指标说明](三分类结果验证与评价指标说明.md) 中的统一评价口径。
