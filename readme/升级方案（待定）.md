# 后续升级候选

本文只记录尚未进入当前稳定链路的候选工作。已经落地的 19 通道背景角色、四类像素级 `pigment`、`background4_v3` 和老化微调不再列为“待升级”。

当前稳定基线见 [训练学习规则](训练学习规则.md)。

## 1. 数据与标签

| 候选项 | 目的 | 预期影响 | 前置条件 |
| --- | --- | --- | --- |
| 扩充不同底材、光照和方向的复杂混合板 | 降低背景与大面积颜料混淆 | 大 | 同一实物板绑定 split，完整人工复核 |
| 增加纯背景老化硬样本 | 同时保住 aging 召回并压低 paint 误报 | 大 | 强制 `paint=0`、`pigment=0`、`pollution=0` |
| 增加边界和弱老化精细标注 | 改善老化断裂、边缘漏检 | 中到大 | 统一边界标注口径 |
| 建立正式独立测试集 | 避免只看训练内或目视样本 | 大 | 背景、病害、方向覆盖均衡 |

## 2. 训练与评价

1. 把“石青背景上的代赭召回率”“大面积颜料召回率”“纯背景老化的 aging 召回率与 paint 误报面积”固化为版本验收指标。
2. 为各背景角色分别统计混淆，而不是只看全局平均 IoU。
3. 对 `paint / pollution / aging` 分头校准阈值，并保留统一阈值作为可比较基线。
4. 评估更强的 hard-example sampling，但不得破坏 v2 冻结集上的回归表现。
5. 训练产物应固定记录代码提交、样本清单、split、patch 数量、随机种子和权重哈希。

## 3. 推理与 UI

| 候选项 | 影响 |
| --- | --- |
| UI 显示权重哈希、通道配置和阈值 | 减少“名称相同、实际文件不同”的迁移错误 |
| 按背景角色自动拆分批量预测 | 避免混合背景样本被同一 `background-role` 运行 |
| 增加迁移验收页 | 便于 CPU 电脑快速对比固定样本的新旧结果 |
| 为人工保存结果增加版本锁定 | 防止切换模型后误把旧标注当成新预测 |

## 4. 暂不建议

- 不在缺少可靠真值时继续用 `SAMPLE_094–096` 做定量优劣结论。
- 不仅凭预测颜料图生成训练标签；预测只能作为人工标注草稿。
- 不把 UI 指定背景解释为“其他颜料不能大面积出现”。
- 不在没有独立对照实验时同时更换网络、损失、数据和后处理，否则无法判断收益来源。
