# 矿物颜料与重点波段简表

本文服务于当前正式 **5 通道主线**。

当前固定波段为：
- `450 nm`
- `550 nm`
- `600 nm`
- `650 nm`
- `700 nm`

这些波段主要用于：
- 样卡制作
- 滤光片理解
- 采集阶段的颜色 / 材料区分参考

最终模型输出仍然是：
- `paint`
- `pollution`
- `aging`

而不是直接输出“石青 / 石绿 / 朱砂”等颜料类别。

## 当前推荐优先准备的样本材料

- 石青
- 石绿
- 朱砂
- 蛤粉
- 炭黑

## 当前简短结论

- `450 nm` 更适合拉开蓝色相关差异
- `550 nm` 对绿色区域最关键
- `600 / 650 nm` 对红色区域最关键
- `700 nm` 作为长波补点，帮助拉开白色、黑色和覆盖差异

当前正式主线固定使用的是这 `5` 个点，不再按“当前默认 6 通道”理解。
