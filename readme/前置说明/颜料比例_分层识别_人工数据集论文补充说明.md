# 颜料比例、分层识别与人工数据集论文补充说明

本文只保留一个更清晰的结论：

- 哪些方向和当前正式主线一致
- 哪些方向已经超出了当前正式主线

当前正式主线是：

- `450 / 550 / 600 / 650 / 700 nm`
- `paint / pollution / aging`
- `5` 通道三头分割

所以这份文档讨论的内容，本质上都属于**后续扩展目标**，不是当前仓库的直接训练目标。

## 一、哪些方向超出了当前主线

| 方向 | 代表论文 / 数据集 | 为什么超出当前主线 |
| --- | --- | --- |
| 同一像素多颜料比例估计 | Chen et al., 2026; Thangka 2025; unmixing dataset 2019 | 这是解混 / 丰度估计，不是当前三头分割 |
| 上下层识别与上层厚薄判断 | Legrand et al., 2014; Kaszewska et al., 2013; Kechaoglou et al., 2024 | 这是分层结构问题，通常需要额外模态，不是当前二维 5 通道分割 |
| 专门面向比例真值的数据集 | unmixing dataset 2019 | 目标是配比和成分真值，不是当前三张区域 mask |

## 二、哪些内容对当前主线仍有间接价值

| 论文 / 数据集 | 间接价值 | 当前怎么理解更合适 |
| --- | --- | --- |
| Wang et al., 2024（automatic labeling framework） | 真值构建、专家标注、算法辅助标注 | 直接有助于当前三头数据集建设 |
| HYPERDOC dataset, 2025 | mock-up 样本与真实样本并行的数据集思路 | 对当前样卡体系和数据集工程有借鉴意义 |
| Thangka pigments mixing-ratio study, 2025 | 混合颜料样块设计 | 可用于以后做“已知比例样卡” |
| Chen et al., 2026 | abundance mapping 思路 | 可作为以后从区域识别扩展到比例估计的起点 |

## 三、如果以后要扩展，最合理的顺序

| 阶段 | 建议目标 | 为什么这样排 |
| --- | --- | --- |
| 第一步 | 先把当前 `paint / pollution / aging` 三头主线做稳 | 先保证正式 5 通道分割数据和评估体系可靠 |
| 第二步 | 增加 mock-up 样卡和更强真值 | 为更复杂任务准备可控数据 |
| 第三步 | 尝试颜料比例估计 | 这一步需要已知配比样本，而不是只靠真实壁画图像 |
| 第四步 | 尝试上下层 / 分层识别 | 这一步通常需要引入额外模态或更强验证手段 |

## 四、当前最值得保留的结论

| 主题 | 当前结论 |
| --- | --- |
| 颜料比例估计 | 不是当前主线，应理解为后续高级任务 |
| 上下层识别 | 不是当前 5 通道三头分割能直接解决的问题 |
| 人工数据集 | 当前最值得做的是继续完善三张独立真值和 mock-up 样卡 |
| 直接可用的参考 | automatic labeling framework 2024, HYPERDOC, MuralDH |

## 五、当前简短结论

这份文档涉及的“颜料比例、分层识别、已知配比真值”都比当前正式主线更进一步。
对当前项目更实用的理解是：

- 先把 `5` 通道 `paint / pollution / aging` 三头分割做好
- 再基于 mock-up 样卡和更强真值体系，逐步扩展到比例估计和分层识别
