# 相机与镜头采购建议（450–700 nm）

本文只保留当前项目的最终采集建议。

目标仍然是服务后续：
- `paint`
- `pollution`
- `aging`

三头任务的数据采集，而不是普通彩色拍照。

## 当前采集端需求

- 支持 `450–700 nm` 范围内的多波段拍摄
- 能与电动滤光轮配合，逐波段输出图像
- 图像适合后续配准、标注和分割训练
- 尽量保留稳定灰度层次和空间细节

## 当前正式口径

当前正式主线固定使用 `5` 个波段：
- `450`
- `550`
- `600`
- `650`
- `700`

所以这里讨论的采集设备，是为当前 **5 通道数据集** 服务。

## 简短建议

- 相机优先黑白工业相机
- 镜头优先 `12mm`
- 如果视野受限，再考虑 `8mm`
- `6mm` 不作为当前默认方案

原因很简单：
- 黑白相机更适合逐波段采集
- 全局快门更利于多波段之间保持几何一致
- `12mm` 在视野、畸变和标注稳定性之间更均衡
