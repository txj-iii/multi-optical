# 样卡底材推荐说明

本文整理当前项目在制作矿物颜料、老化和污染样卡时可选的底材方案，并按与壁画任务的贴合度给出推荐顺序。

## 一、推荐顺序

结合当前项目目标，即输出壁画表面的：

- `paint`
- `pollution`
- `aging`

底材推荐顺序如下：

1. 熟石膏粉 + 水做底板
2. 白色瓷砖
3. 刷白色乳胶漆的硬纸板
4. A4 纸

## 二、各方案说明

### 1. 熟石膏粉 + 水做底板

推荐程度：

- `最高`

推荐原因：

- 最接近真实壁画地仗层
- 漫反射和表面状态更贴近壁画
- 更适合制作正式样卡
- 更适合模拟裂缝、剥落、磨损、污染覆盖等情况

适合用途：

- 正式采集样卡
- 正式训练样卡
- 人工标注样卡
- 老化和污染模拟样卡

### 2. 白色瓷砖

推荐程度：

- `高`

推荐原因：

- 成本低
- 表面平整
- 便于均匀涂抹颜料
- 适合先调试相机、滤光片和曝光流程

局限：

- 表面过于光滑
- 与真实壁画基层差异较大
- 不太适合做自然的裂缝、剥落和粉化效果

适合用途：

- 前期系统调试
- 颜色样块拍摄
- 滤光片波段对比
- 采集流程验证

### 3. 刷白色乳胶漆的硬纸板

推荐程度：

- `中`

推荐原因：

- 便宜
- 容易快速制作
- 比直接用纸更稳定

局限：

- 乳胶漆会引入额外表面特性
- 与真实壁画基层差距较大
- 真实性弱于石膏和瓷砖

适合用途：

- 低成本预实验
- 标注流程验证
- 算法逻辑验证

### 4. A4 纸

推荐程度：

- `最低`

局限：

- 不适合作为正式采集和正式标定底材
- 与真实壁画基层差异太大
- 容易引入纸张本身的材料影响

适合用途：

- 仅用于临时代码测试
- 临时验证采集流程
- 临时验证数据堆叠和算法逻辑

## 三、当前项目最推荐的实际做法

如果条件允许，建议分成两类底材同时准备：

- 正式样卡底材：熟石膏底板
- 调试样卡底材：白色瓷砖

这样做的好处是：

- 瓷砖用于前期快速调系统
- 石膏用于正式采集、标注和训练

如果只能选一种底材，则当前项目最推荐：

- 熟石膏粉 + 水做底板

## 四、当前简短结论

对于当前壁画 `paint / pollution / aging` 三分类项目，最推荐的样卡底材是熟石膏底板，因为它最接近真实壁画基层，也最适合后续多波段采集和病害模拟。白色瓷砖适合作为调试阶段的低成本底材，而乳胶漆硬纸板和 A4 纸更适合作为临时验证材料，不建议作为正式训练和标定底材。
