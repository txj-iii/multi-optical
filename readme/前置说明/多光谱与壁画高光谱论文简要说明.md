# 多光谱与壁画高光谱论文简要说明

本文重点回答两个更实用的问题：

- 哪些论文和数据集对当前方案有直接支撑
- 哪些更适合作为后续扩展方向

当前方案指的是：

- 固定 `5` 通道输入
- 固定波段：`450 / 550 / 600 / 650 / 700 nm`
- 三头输出：
  - `paint`
  - `pollution`
  - `aging`
- 数据路线：
  - `camera_eval_workspace -> 人工标注 -> five_band_patches`

## 一、对当前方案直接有支撑的论文 / 数据集

| 论文 / 数据集 | 作用类型 | 对当前方案的支撑点 | 当前优先级 |
| --- | --- | --- | --- |
| Jones et al., 2020 | 多光谱最佳实践 | 支撑“采集、校准、配准、处理”应作为完整流程，而不是只拍图 | 高 |
| Wang et al., 2024（visible spectral imaging for pigment identification） | 可见光光谱成像 | 直接支持当前 `450–700 nm` 可见波段用于材料和区域区分 | 高 |
| Han et al., 2015 | 壁画隐藏信息提取 | 支撑污染 / 遮挡下仍需要保留光谱信息，和 `pollution` 很相关 | 高 |
| Pan et al., 2017 | 褪色壁画提取 | 直接支持 `aging` 相关区域需要“空间 + 光谱”共同判断 | 高 |
| Hou et al., 2019 | 烟熏遮挡增强 | 直接支持 `pollution` 与底层图案可分离的思路 | 高 |
| Wang et al., 2024（automatic labeling framework for paint loss disease） | 标注 / 真值构建 | 对“人工标注 + 算法辅助”的数据集建设最有参考价值 | 高 |
| HYPERDOC dataset, 2025 | 数据集工程 | 支持“真实样本 + mock-up 样本并行”的数据集设计思路 | 中高 |
| MuralDH dataset paper, 2024 | RGB 辅助分割数据集 | 直接支持 `MuralDH.zip` 作为辅助预训练数据源 | 高 |

## 二、对当前方案有参考价值，但不是主线核心

| 论文 / 数据集 | 为什么不是当前核心 | 仍然有什么价值 | 更适合的阶段 |
| --- | --- | --- | --- |
| Delaney et al., 2016 | 更强调更宽谱覆盖；当前正式主线收缩到 `450–700 nm` | 可作为以后是否扩到更宽谱段的依据 | 后续扩谱 |
| Pelagotti et al., 2018 | 更偏自动颜料识别，不是当前三头分割主目标 | 适合以后从“区域识别”扩到“材料识别” | 后续 |
| HYPERDOC dataset, 2025 | 不是壁画数据 | 适合作为人工数据集设计参考，不适合作为最终验证标准 | 后续 |
| A laboratory-created dataset for unmixing, 2019 | 目标是解混比例，不是当前三头分割 | 对未来做已知配比样卡很有帮助 | 后续 |

## 三、更偏后续扩展方向的论文

| 论文 | 更适合支撑什么 | 为什么不属于当前主线 |
| --- | --- | --- |
| Chen et al., 2026 | 同一像素多颜料比例估计 / abundance mapping | 这是解混与丰度反演，不是当前 `paint / pollution / aging` 分割 |
| Thangka pigments mixing-ratio study, 2025 | 混合颜料比例估计 | 目标是比例输出，不是当前区域分割 |
| Legrand et al., 2014 | 上下层 / 分层结构识别 | 需要更强的多模态或深度信息，不是当前二维 5 通道分割 |
| Kaszewska et al., 2013 | 分层厚度与上下层判断 | 依赖 `LIBS / OCT`，不是当前采集链 |
| Kechaoglou et al., 2024 | stratigraphy 分层分析 | 更偏层次结构研究，不是当前主任务 |

## 四、最实用的归纳

对当前 `5 通道 + 三头分割` 主线最直接有支撑的，是：
- Jones 2020
- Wang 2024
- Han 2015
- Pan 2017
- Hou 2019
- automatic labeling framework 2024
- MuralDH dataset paper

而下面这些更适合作为后续扩展参考，而不是当前主线的核心依据：
- Chen 2026
- Thangka 2025
- Legrand 2014
- Kaszewska 2013
- Kechaoglou 2024
