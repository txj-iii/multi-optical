# 老化与污染样卡制作建议

本文整理当前项目中 `aging` 和 `pollution` 两类样卡的建议做法，目标是为后续多波段采集和 `paint / pollution / aging` 三分类训练提供更可控的人工样本。

## 一、为什么不要只靠“划一道口”

如果只是在表面随便划一道口，虽然可以制造局部损伤，但通常存在以下问题：

- 纹理过于单一
- 更像机械划伤，不像自然老化
- 不利于模拟真实壁画中的裂缝、剥落、磨损和粉化

因此更推荐把 `aging` 和 `pollution` 分开设计成多种可控样卡，而不是只做一种人为损伤。

## 二、建议制作的 `aging` 样卡类型

| 类型 | 目标 | 建议做法 | 适合表现 |
| --- | --- | --- | --- |
| 裂缝样卡 | 模拟表层开裂 | 让较薄涂层自然干燥收缩形成细裂，或在完全干燥后对基底做非常轻微弯折 | 比刀划更接近真实裂缝纹理 |
| 剥落样卡 | 模拟颜料层局部脱落 | 颜料层干燥后，用镊子或小刀轻轻去掉局部表层，露出底层或白色基底 | 适合标记 `aging`，同时仍保留剩余 `paint` |
| 磨损样卡 | 模拟长期摩擦后的局部减薄或失色 | 用棉签、软布或细海绵做局部轻擦，边缘尽量保留渐变 | 适合模拟轻度老化 |
| 粉化 / 褪色样卡 | 模拟表层变淡、失色、表面松散 | 颜料层做薄，干后做轻微擦拭或局部减薄 | 可作为 `aging` 的轻度样本 |

## 三、建议制作的 `pollution` 样卡类型

| 类型 | 目标 | 建议做法 | 适合表现 |
| --- | --- | --- | --- |
| 薄覆盖层样卡 | 模拟表面存在较薄污染层，但下方仍可见原始颜料 | 在颜料层上轻薄撒布炭黑或石墨粉，再做轻微固定 | 适合模拟烟熏、沉积、薄污层，也适合测试“上层薄、下层仍可见” |
| 厚覆盖层样卡 | 模拟较重污染或覆盖异常 | 用较厚的炭黑或黑灰色粉末覆盖局部区域 | 比薄层更容易识别，适合作为重污染对照 |
| 局部污斑样卡 | 模拟不规则污斑和斑块状覆盖 | 不要均匀铺一层，而是做成不规则边界和局部斑点 | 更接近真实壁画污染分布 |
| 边缘堆积样卡 | 模拟污染在裂缝边缘或凹陷边缘堆积 | 在已有裂纹或局部凹陷周围增加黑色粉末 | 更接近污染与老化共同存在的真实情况 |

## 四、推荐的基础样卡结构

建议按下面的结构组织基础样卡：

| 维度 | 建议内容 | 用途 |
| --- | --- | --- |
| 底层颜色 | 石青、石绿、朱砂、蛤粉 | 作为 `paint` 基础层 |
| 纯净样卡 | 仅保留底层颜料，不叠加老化或污染 | 作为对照样本 |
| 老化样卡 | 裂缝、剥落、磨损、粉化 / 褪色 | 对应 `aging` |
| 污染样卡 | 薄覆盖层、厚覆盖层、局部污斑、边缘堆积 | 对应 `pollution` |
| 叠加样卡 | 污染 + 老化共同存在 | 用于模拟更接近真实场景的复合样本 |

## 五、需要准备的工具

| 工具类别 | 建议清单 | 主要用途 |
| --- | --- | --- |
| 基础材料 | 石青、石绿、朱砂、蛤粉、炭黑或石墨粉、白色基底板或测试样板 | 制作底层颜料和污染层 |
| 颜料与上样工具 | 小调色盘、小勺或取样勺、细毛笔、小刮刀、滴管、调色棒 | 调色、取样、上样 |
| 结构处理工具 | 镊子、棉签、软布、细海绵、小刀或雕刻刀 | 制作裂缝、剥落、磨损等效果 |
| 记录与标记工具 | 尺子、标签纸、编号笔、相机支架或固定台 | 编号、记录、固定采集条件 |
| 安全工具 | 一次性手套、口罩、桌面防护纸 | 防护和操作安全 |

## 六、如果是颜料，应该怎么弄

当前建议优先使用粉状矿物颜料，而不是已经预调好的复杂绘画成品。

建议做法：

1. 先准备白色底板或基底
2. 将少量矿物颜料取出
3. 根据需要加入极少量水或简单粘结介质
4. 先做单色平涂样块
5. 待其干燥后，再制作裂缝、剥落、污染等变化

注意：

- 每次只配少量，便于控制
- 不同颜色尽量分别操作，避免交叉污染
- 同一类样卡尽量控制厚度一致
- 每张样卡都要编号并记录制作方式

## 七、颜料处理上的注意事项

### 1. 尽量先做“纯净底层”

先做没有老化和污染的底层样卡，再在其上叠加变化。这样更利于后续比较和标注。

### 2. 薄层与厚层要分开做

同一种污染材料，建议至少做：

- 薄层
- 厚层

这样后续更适合比较多波段响应差异。

### 3. 变化不要一次做得太重

如果一开始就做得很极端，虽然肉眼容易看见，但不利于后续测试模型对轻度病害和轻度污染的识别能力。

### 4. 朱砂操作要注意安全

朱砂不建议大量研磨、扬尘操作，尽量少量使用，并做好防护。

## 八、当前简短结论

当前项目的 `aging` 和 `pollution` 样卡不建议只靠“划一道口”来完成，更推荐通过裂缝、剥落、磨损、粉化、薄覆盖层、厚覆盖层、污斑和边缘堆积等方式构造更接近真实壁画病害的人工样本。制作时建议以石青、石绿、朱砂、蛤粉为底层材料，以炭黑或石墨粉作为污染层材料，并结合基础工具和简单工艺建立一批可控、可记录、可标注的测试样卡。
