# 当前五波段训练与预测规则

本文是当前训练、预测、版本隔离和验收的唯一技术口径。样本来源与逐样本状态见
[样本记录规范.md](D:/multi-optical/readme/样本记录规范.md)。

## 1. 当前版本体系

当前同时保留两套版本体系，不能混为一谈。

### 1.1 论文历史版本（15通道）

论文《基于五波段多光谱成像的壁画表面三类病害同步分割框架》中的版本为：

- `version 1`：五波段派生15通道、三头联合训练的基线
- `version 2`：在 version 1 上加入 soft competition、污染阈值与形态过滤，并对复杂样本使用
  paint 专项覆盖。

论文 version 1 / version 2 不等于 `background4_v1 / background4_v2`。

论文历史训练来源保留：

- `retune_9_scene3647_pollutionshape_v2`
- `retune_9_scene3647_agingmix_4849_v1`
- `retune_9_scene3647_v10_balanced_softcomp_4849_pollution4447_v1`

论文历史预测与对照保留：

- `retune_9_scene3647_pollutionshape_v2_shapefilter_all`
- `retune_9_scene3647_final_v3_paint4849fix`
- `validation_v10_balanced_softcomp_5056_pollthr035`
- `comparisons`

### 1.2 当前 background4 版本（19通道）

当前 background4 推理链为：

```text
background4_v2
  -> background4_v3
  -> background4_v3_agingfix_v1_best
```

用途：

- `background4_v2`：当前 UI 中 background4 推理默认版本。
- `background4_v3`：吸收 `SAMPLE_097–119` 后的10轮正式候选。
- `background4_v3_agingfix_v1_best`：从 v3 继续微调，重点修复 aging 与背景误报；采用第4轮最佳权重。

三个版本必须使用独立 checkpoint 和独立预测目录，禁止互相覆盖。

## 2. 输入与模型任务

### 2.1 19通道输入

background4 模型固定使用19通道：

```text
5个原始波段
+ 4个相邻波段差值
+ 4个相邻波段比值
+ 2个归一化波段差异
+ 4张背景类型 one-hot 常量图
= 19通道
```

四种背景条件固定为：

- 代赭
- 石青
- 石绿
- 朱砂

背景条件只用于压低对应底板误报，不是颜料类别，也不能限制真实前景颜料面积。

### 2.2 四个训练任务

- `paint`：颜料或绘制主体区域。
- `pollution`：外来污染与附着物。
- `aging`：老化、褪变等病害。
- `pigment`：paint 内四类像素级颜料分割。

像素级 pigment 类别固定为：

1. 朱砂
2. 代赭
3. 石青
4. 石绿

约束：

- `pigment` 只在人工确认的 `paint` 内计算损失。
- 必须满足 `pigment > 0` 的像素均位于 `paint > 0` 内。
- 背景板底色不写入 `paint` 或 `pigment`。
- 预测 pigment 只能作为人工标注草稿，未经确认不得作为训练真值。

旧15通道模型中的7类 patch 级 pigment 头只属于论文历史版本，不再作为 background4 训练口径。

## 3. 当前训练数据

### 3.1 冻结基础集

- 40个场景。
- 1,500个 patch。
- 路径：`train/five_band_patches/background4_v1/`
- 内容只读，不覆盖、不重新导出。

虽然目录名是 `background4_v1`，它仍是 v2/v3 的冻结基础数据，不能删除。

### 3.2 v3增量集

- `SAMPLE_097–119` 共23个场景。
- 846个 patch。
- 路径：`train/five_band_patches/background4_v3/`

正式 v3 清单为：

```text
40个基础场景 + 23个增量场景 = 63个场景
1,500个基础patch + 846个增量patch = 2,346个patch
```

每个 epoch 的采样比例约为：

- 冻结基础集：67%
- v3增量集：33%

随后再按 paint / pollution / aging 阳性组合做均衡采样。

### 3.3 不可拆分采集组

以下同板方向或光照副本必须处于同一 split：

- `097–099`
- `100–102`
- `103–104`
- `105–110`
- `111–112`
- `113–116`
- `117–119`

禁止把同一实物板的方向、旋转或光照副本拆到 train / validation / test 的不同集合。

### 3.4 外部观察样本

`SAMPLE_094–096` 不进入训练，不导出训练 patch。

当前这三组存在背景记录冲突，且没有确认的人工真值，因此：

- 只能作为外部目视观察输入。
- 不能把预测草稿当成正式 mask。
- 不能使用历史预测草稿计算正式 IoU。
- 背景板信息统一前不得重新批量预测或写入验收结论。

## 4. 标签与困难样本规则

### 4.1 大面积颜料

UI 指定背景板不能压掉真实前景颜料。例如石青背景上的大面积代赭，人工确认后必须完整写入：

- `paint`
- 代赭 pigment 像素

### 4.2 纯污染样本

纯污染样本只训练 `pollution`，必须保持：

```text
paint=0
aging=0
pigment=0
```

### 4.3 石青纯背景老化

`SAMPLE_117–119` 只训练 aging，必须保持：

```text
paint=0
pollution=0
pigment=0
```

训练目标同时包括：

- 保留真实 aging。
- 抑制石青背景被识别为 paint。
- 抑制 aging 同时被 pollution 或 paint 重复输出。

### 4.4 ROI

- 优先使用人工确认的 `board_roi.json`。
- 训练 patch 与最终预测必须采用一致板框。
- 最终 paint / pollution / aging / pigment 输出与 ROI 硬相交。
- ROI 外像素强制为0。
- ROI 缺失且自动检测失败时必须终止，不能回退整张相机图。


- `SAMPLE_060 paint IoU=0.699`
- `SAMPLE_082 / 083 paint IoU=0.635 / 0.708`

## 7. 预测规则

正式入口：

```text
train/predict.py
```

background4 checkpoint 必须传入有效背景板：

```text
--background-role 代赭 / 石青 / 石绿 / 朱砂
```

缺少背景板时必须报错，不能静默预测。

版本与目录对应关系：

| 版本 | checkpoint | 输出目录 |
| --- | --- | --- |
| v2 | `background4_v2/background4_v2.pt` | `background4_v2/` |
| v3 | `background4_v3/background4_v3.pt` | `background4_v3/` |
| v3 agingfix | `background4_v3_agingfix_v1/background4_v3_agingfix_v1_best.pt` | `background4_v3_agingfix_v1_best/` |

同一背景板的多个样本可以一次运行；不同背景板必须分开运行。

同版本、同样本、同输出目录重新预测会覆盖同名预测文件，但不会覆盖：

- 其他模型版本
- `camera_eval_workspace` 中的人工 masks
- `five_band.npy`
- `preview.png`

完整命令见
[v3与v3微调版预测命令.md](D:/multi-optical/readme/v3与v3微调版预测命令.md)。

## 8. UI版本口径

UI 中存在两类预测概念：

1. `validation_v10_balanced_softcomp_5056_pollthr035`
   - 论文 version 2 / UI review 起标链。
   - 用于产生可编辑标注草稿。

2. `background4_v2 / v3 / v3_agingfix_v1_best`
   - 19通道背景条件模型。
   - 需要先确认背景板。
   - background4 下拉框默认仍为 v2，v3和agingfix用于对照。

UI 的“保存标注”和“采用标注”不会自动训练模型。

## 9. 验收规则

每次新 checkpoint 至少检查：

- 旧代赭代表 paint。
- 石绿背景 paint。
- 石青背景大面积前景颜料。
- 复杂 paint + pollution。
- 复杂 paint + aging。
- 石青纯背景老化的 aging IoU。
- 石青纯背景老化的 paint / pollution 误报面积。
- ROI 外非零像素数量。

所有指标应按背景、颜料类别、面积等级、光照和方向拆分；同板副本不能当成独立泛化样本。

任一头明显退化时，该 checkpoint 不得设为 UI 默认模型。
