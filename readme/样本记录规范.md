编号、标注与分组约束：

- `097–099` 是同一原始板的方向副本，必须固定在同一 split；训练前 `pigment.png` 必须非零且只落在 `paint` 内。
- `100–101` 是同一目录内的两次独立采集，不可当成单一 10 波段样本。
- `103–104` 按不可拆分采集组处理，固定在同一 split。
- 纯污染组不得因石绿背景而标入 `paint`；混合组的背景代赭不进入颜料类别，只有新增的可确认颜料子区写入 `pigment.png`。
- `105–107` 是同一 C 朝向板在不同光照下的副本；`108–110` 是同一 A 朝向板在不同光照下的副本。各自必须绑定到同一 train/val/test split。
- `111–112` 是“颜料+老化”光照副本；`113–116` 虽按时间拆成四次采集，当前训练仍按同组固定在同一 split。
- 朱砂背景板绝不因底色而写入 `paint` 或 `pigment`；只有可确认的新增颜料区域才进入这两类标签。
- `105–116` 的来源目录只写“颜料”时，不根据颜色猜测类别；须在 UI 中按可确认子区标为朱砂 / 代赭 / 石青 / 石绿，无法确认的像素保留 ignore。
- `117–119` 是同一石青纯背景老化板的光照副本，必须固定在同一 train/val/test split。
- 它们是“背景不误报为 paint”与“真实 aging 必须保留”的硬样本；不得因为背景为石青而把老化压成空白。
- 训练前必须保持 `paint / pigment / pollution` 全零，仅保留人工确认的 `aging`。

### 明确排除

- `SAMPLE_001–035`：不属于 `background4_v1 / background4_v2` 冻结训练集。
- `SAMPLE_051、052、054、056–059`：不进入 `background4_v1 / background4_v2`；其中 `SAMPLE_057` 仅保留历史目录。
- `SAMPLE_094–096`：不入训、不导出训练 patch；当前无确认真值且背景记录冲突，只作外部目视观察。
- `SAMPLE_097–119`：已经人工保存或确认迁移并正式采用；后续不得把“已导入 UI”自动等同于新样本已采用。

### 几何、背景与 split 规则

- A/a：正向 0°；B/b：顺时针 90°，在原始画布内旋转，禁止拉伸；C/c：倒置 180°，必要时保留人工确认的微小平移校正。
- 已知背景类型必须在 UI 中保存为 `background_role`：`代赭 / 石青 / 石绿 / 朱砂`。背景只用于分背景评估、误报统计和预测校准，不是颜料类别，也不限制其他颜料面积。
- 当前冻结 patch 位于 `train/`；正式训练必须按原始采集母本组拆分 train/val/test，同一母本及其光照、方向副本必须留在同一 split，禁止按 patch 随机拆分。
- 朱砂背景后续含颜料样本应保留独立验证组；纯背景样本用于约束背景误报，但采样数量不得压过含颜料前景样本。

## 标注判定与复核口径

这一节专门记录“样本该怎么标”，后续新增样本、复核旧样本、人工修正自动标注时，优先看这里，不要再把这部分混在训练参数里。

### paint

- paint 按“真实颜料主体”判定，不按“只要波段有变化就算颜料”判定。
- 明确的颜料主体、笔画、连续涂覆区、已确认的颜料点状区，记为 paint。
- SAMPLE_027 这类已确认是颜料的点状区，仍归 paint，不并入 pollution。
- 不能因为某块区域偏绿、局部有变化、或视觉上接近石青，就自动并入 paint。
- 一旦确认属于 paint，主体要尽量标完整，不能只留最深、最亮或最粗的一部分。

### pollution

- pollution 优先按“外来附着的泥土 / 污块语义”判定，不按单一颜色判定。
- 常见形态是团块状、近圆形、椭圆形、附着感较强的深色或深绿色区域。
- 即使颜色偏绿，只要更像附着污块，而不是原本写上去的颜料主体，仍归 pollution。
- 对绿色系难样本，优先看它和 paint 主体的关系：如果与主体有间隔、边界更像单独附着团块，就优先按 pollution 处理。
- 绿色 / 深色本身不是充分条件；真正关键的是“是否存在独立附着感、边界是否不规则、是否像后落上去的一整团污染”。
- 如果一整片深绿只是底色、铺底笔触或较平滑的大面积颜料变化，即使颜色更深，也不要直接并入 pollution。
- pollution 要尽量圈“整体总边界”，不能只抓最深绿色核心。

### aging

- 划痕、裂痕、擦伤、老化造成的细长痕迹或面状磨损，统一归 aging。
- 原则上划痕不并入 paint，除非已经确认它本身就是颜料主体的一部分。

### SAMPLE_044 / SAMPLE_047 的当前口径

这几个样本容易误判，因为污染区域都偏绿，视觉上会接近石青，但当前正式语义不是“看起来绿就算污染”，而是看它是不是“附着在板面上的外来污块”。

- SAMPLE_044：当前保留的是右侧往左下延伸的那整片深绿色附着块。判断依据不是“最深绿色核心”，而是“这是一整团附着污染，总边界要按整体去圈”。因此复核时应优先看整体团块边界，不要只截内部高对比核心。
- SAMPLE_045：当前保留的是右上区域那团深绿色附着污染。它和 SAMPLE_044 同属“绿色附着污块”语义，但空间位置不同，不能直接照抄 044 的边界。
- SAMPLE_046：右下两团污染才是正式目标；大片深绿底色、较平滑的朱砂铺底变化、以及整板暗绿色纹理都不是污染。对这类样本，复核重点不是“哪里最绿”，而是“哪里形成了独立、不规则、像后附着上去的团块边界”。
- SAMPLE_047：同样按“独立附着团块”判，不按绿色深浅判；凡是与主体笔触连续、边界更平滑、只是底色或颜料铺展的一部分，都不要并入 pollution。
- 对这几类样本，绿色只是外观特征，真正决定标签的是“是否为独立附着团块、是否与颜料主体分离、是否应按整体污染边界处理”。

### 自动 / 半自动起标默认流程

- 先看 preview.png，先按人工语义判断这张图理论上有哪些头：paint / pollution / aging。
- 优先找最接近的旧样本作为参考，不只看类别名，还要看主体位置、污染位置、是否为空白、是否有划痕。
- 纯空白样本默认三头全空，不人为补弱噪声。
- 纯污染样本先只做 pollution；纯颜料样本先只做 paint；混合样本先拆出明确颜料主体，再单独找外来附着污染。
- 自动起标时先限制在实际石膏板内部，再做颜色或强度分割，避免把黑边、外框、光照渐变一起吃进去。
- 自动结果出来后必须看叠图复核；当前 UI 首轮标注底稿来自 `review` 预测，系统会先写入 `masks` 作为可编辑草稿。凡是整片底板被吃进去、边框被吃进去、主体明显缺边、粉末并进 paint、或颜料被误判成 pollution，都必须人工修订并保存后才能作为 candidate / 主训练复核的标注依据。
- 如果自动结果把整块背景一起连进去，优先删除接触 ROI 边界的大连通块，只保留内部真正成形的主体或污染团块。
- 对 SAMPLE_035 这类边缘伪影明显的样本，必须用“板内约束 + 分区域收真实笔画 + 删除贴边伪影”的方式处理，不能用一条全局阈值直接收整板。
- 后续新增绿色污染难样本时，默认先参照 SAMPLE_044 / SAMPLE_045 这条语义：先判定是否为独立附着团块，再决定边界大小。
